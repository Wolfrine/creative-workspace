# Noveliaa visual prototypes

Exploratory multi-device design references, **not implementation specifications**. Optimized WebP copies are included for direct use by Codex. The full-resolution PNG originals are preserved in the [Novel Writing Space gallery](https://chatgpt.com/space/page_6adb3f8f2624819196ab0baa159f3157).

## Owner preference (23 October 2026)

1. **[Living Atlas](02-living-atlas.webp) — first choice.** An inviting, contextual view of story worlds and connections.
2. **[Quiet Folio](01-quiet-folio.webp) — second choice.** Calm, focused long-form writing.
3. **[Story Workbench](04-story-workbench.webp) — third choice.** Explicit review, proposals and provenance.
4. **[Night Atelier](03-night-atelier.webp) — alternate only.** Retained for reference, not shortlisted.

Use Living Atlas as a useful optional navigation experience; the actual writing canvas should remain simple and distraction-free.
