## Truth and review conditions declared before scoring

- Task/context: universe switches cannot retain foreign collection/query state;
  Library selection and return paths are predictable; Atlas inspection stays in
  Atlas until an explicit writing action. A thought is a page started quickly,
  not another data type. Avoid competing visible creation controls.
- Prose/motion: a turn carries the actual outgoing writing and reveals incoming
  writing, with forward/backward direction and clean settlement. No empty
  gradient pretending to turn a page. Text stays selectable, exact and semantic;
  links, bookmarks, last/odd spreads and rapid turns remain correct.
- Hierarchy/restraint: one useful primary action, recognizable page/collection
  identity, content-led Tile/List/Detailed views, no fabricated cover art or
  decorative metrics. Provenance remains visible and AI-origin stays unverified.
- Responsive/access: 320/390/768/1440 CSS px, single/facing pages, reachable
  controls, keyboard/links/focus, reduced motion and an explicit animation-off
  choice. These are browser conditions, not physical-phone or human comfort proof.

First-glance hypotheses: words or Library entries dominate; current universe
and collection become identifiable; the next useful action is apparent without
extra setup. No human attention timing is asserted.
